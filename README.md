# Golden Crust Bakery – Website Project

This repository contains the Formative 1 (Part 1) submission for WEDE5020 – Web Development (Introduction).

## Project Overview
Golden Crust Bakery is a fictional local small business (bakery) created as the target organisation for this website project. The goal of the project is to build a functional, visually appealing, and easy-to-navigate website for the bakery.

## Folder Structure
```
/
├── index.html          Homepage
├── about.html          About Us page
├── products.html        Products page (breads, pastries, cakes)
├── enquiry.html         Custom order enquiry form
├── contact.html         Contact details, map, and contact form
├── css/
│   └── style.css        Main stylesheet
├── js/
│   └── script.js        Form validation and small interactivity
├── images/               Local image assets (if any added later)
└── documents/            Wireframe and sitemap diagrams
```

## Technologies Used
- HTML5
- CSS3
- JavaScript (vanilla)
